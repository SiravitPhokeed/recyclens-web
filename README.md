# RecycLens

<p><img width="2532" height="1131" src="https://github.com/user-attachments/assets/1262c3dd-059e-415a-821f-e8877337fd69"></p>

Point. Tap. Know. RecycLens makes recycling easy by providing localized recycling information for your area. Simply point your camera at an item, tap to identify it, and get instant recycling guidelines tailored to your location. Visit the preview at [recyclens.vercel.app](https://recyclens.vercel.app).

RecycLens was built by our team, The Garbologists, during [Uber Global Hackathon 2022](https://web.archive.org/web/20220828023819/https://www.uberglobalhackathon.org/). It was [the regional winner](https://web.archive.org/web/20220828023409/https://www.uberglobalhackathon.org/regional-winners-2022) for the South, East, and Southeast Asia region in the Coding category.

## Development

```bash
# Install dependencies
pnpm i

# Run the development server
pnpm dev

# Build for production
pnpm build
pnpm start
```
